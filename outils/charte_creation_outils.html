⚡ Mémo Officiel : Procédure de Création & Modification d'Outils

Suis cette liste de vérification étape par étape pour chaque nouveau module ou modification sur l'intranet.

1 Étape 1 : Créer la Table dans Supabase (10 secondes)

Chaque outil possède sa propre table dans la base de données cloud Supabase pour stocker ses données de sauvegarde au format JSON.

-- 1. Va sur Supabase (supabase.com) > SQL Editor (>_)\n-- 2. Colle et exécute ce code en remplaçant "nom_de_l_outil" (ex: public.gestion_planning) :\n\n CREATE TABLE IF NOT EXISTS public.nom_de_l_outil (id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, created_at TIMESTAMPTZ DEFAULT NOW(), data JSONB);\n ALTER TABLE public.nom_de_l_outil ENABLE ROW LEVEL SECURITY;\n CREATE POLICY "Allow public read/write" ON public.nom_de_l_outil FOR ALL USING (true) WITH CHECK (true);

2 Étape 2 : Consigne de Sauvegarde pour l'IA / Gemini

Lors de la création du fichier HTML de l'outil, inclus cette consigne de connexion Supabase :

📋 Bloc à copier-coller pour la création de l'outil :

• Inclure le SDK Supabase CDN : <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
• Initialiser le client : const sbClient = supabase.createClient('https://tumrbyxfnkqobyfzucax.supabase.co', 'sb_publishable_mmpD1yytpJEEJ7FV3oTwzA_Sa55Jf_8');
• Lire et écrire l'état complet de l'outil dans la table Supabase `nom_de_l_outil` dans la colonne `data` (JSONB).

3 Étape 3 : Ajouter le Bouton sur `index.html`

Pour que l'outil apparaisse sur le Dashboard principal et sur la Sidebar latérale :

1. Ouvre `index.html` et ajoute l'outil dans le tableau JavaScript `tousLesOutilsDojoDefaut` :

{ name: "🥋 Mon Nouvel Outil", url: "outils/mon_outil.html" }

✨ **Magie Sidebar :** Le fichier `js/sidebar.js` lit automatiquement `index.html`. Dès que tu ajoutes l'outil dans `index.html`, la barre latérale se met à jour toute seule sur TOUTES les pages !

4 Étape 4 : Déploiement GitHub & Vercel

1. Glisser-déposer sur GitHub Rends-toi dans ton dépôt `intranet.dojodornois`, va dans `outils/`, clique sur **Upload files** et dépose ton fichier. Clique sur **Commit changes**.
2. Mise en ligne Vercel Vercel déploie automatiquement le site en quelques secondes sur `intranet.dojodornois.fr`.
